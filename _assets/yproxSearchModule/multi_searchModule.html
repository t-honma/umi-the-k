- ソースの設置手順について

1.必須Javascriptファイルの貼り付け

以下のソースをhead内の任意の場所に貼り付けます。

※ファイルの場所を変更する場合は、パスの変更も必要です。


<!-- 必須javascript ファイル 開始 -->

<script src="./js/yprox_searchForm.js" defer></script>

<!-- 必須javascript ファイル 終了 -->

3.管理IDを変更する

formタグのaction属性の「管理ID」の箇所を変更頂くことで検索する施設を設定できます。


<!-- formのaction属性の変更 -->

<form name="yprox-searchForm" data-calendar class="js-yprox-searchForm" action="https://www.489pro-x.com/ja/s/管理ID/search/" method="get" role="search">

<!-- formのaction属性の変更 -->

4.【グループ施設契約の場合のみ】グループ管理IDを変更する

formタグのaction属性の「グループ管理ID」の箇所を変更頂くことで検索する施設を設定できます。

※通常の施設契約の場合は「s」のままで検索できます。（管理画面にグループ管理IDの表示はありません）


<!-- formのaction属性の変更 -->

<form name="yprox-searchForm" data-calendar class="js-yprox-searchForm" action="https://www.489pro-x.com/ja/グループ管理ID/管理ID/search/" method="get" role="search">

<!-- formのaction属性の変更 -->

- ソースの変更について

HTMLのソースの変更は、既に指定している各種class名や属性など変更しないようにご注意下さい。
変更されますとエラー等により正しく検索できなくなります。

・カレンダー表示・非表示の設定について

カレンダー表示の設定は、data-calendar属性をformタグに追加することで行います。（初期設定は表示する）
※カレンダー内チェックアウト選択のテキストを表示しない場合は、data-hide-checkout-text属性をformタグに追加することで行います。 


<!-- カレンダー表示する場合 -->

<form name="yprox-searchForm" data-calendar class="js-yprox-searchForm" action="https://www.489pro-x.com/ja/s/管理ID/search/" method="get" role="search">

<!-- カレンダー表示する場合 終了 -->


<!-- カレンダー表示しない場合 -->

<form name="yprox-searchForm" class="js-yprox-searchForm" action="https://www.489pro-x.com/ja/s/管理ID/search/" method="get" role="search">

<!-- カレンダー表示しない場合 終了 -->


<!-- カレンダー内チェックアウト選択のテキストを表示しない場合 -->

<form name="yprox-searchForm" data-calendar data-hide-checkout-text class="js-yprox-searchForm" action="https://www.489pro-x.com/ja/s/管理ID/search/" method="get" role="search">

<!-- カレンダー内チェックアウト選択のテキストを表示しない場合 終了 -->

・日付未定の設定について

日付未定の設定は、data-no-date属性をformタグに追加することで行います。（初期設定は日付未定無効）


<!-- 日付未設定有効 -->

<form name="yprox-searchForm" data-calendar data-no-date class="js-yprox-searchForm" action="https://www.489pro-x.com/ja/s/管理ID/search/" method="get" role="search">

<!-- 日付未設定有効 終了 -->


<!-- 日付未設定無効 -->

<form name="yprox-searchForm" data-calendar class="js-yprox-searchForm" action="https://www.489pro-x.com/ja/s/管理ID/search/" method="get" role="search">

<!-- 日付未設定無効 終了 -->

・表示言語の変更について

カレンダー・JavaScript内で生成される文字の表示言語

以下対応言語に関しては、ブラウザの設定言語ごとに自動で変更されます。それ以外の言語は英語表示となります。

対応言語
日本語・英語・韓国語・中国語（簡体字）・中国語（繁体字）

カレンダー・JavaScript内で生成される文字以外の表示言語

WEBサイト制作者様側で各言語に翻訳をお願いいたします。

・カレンダーの表示位置の変更について

カレンダー表示位置の設定は、data-calendar-position属性を指定することで行います。（初期設定はtop）

以下指定可能な表示位置です

指定可能な表示位置
- top：上揃え（デフォルト）
- bottom：下揃え
- top left：上左揃え
- bottom left：下左揃え
- top right：上右揃え
- bottom right：下右揃え
- auto：js-yprox-searchFormクラスを指定したformの画面上の上下の位置を判別してinputの上下に自動で表示（form要素以外の要素の上下位置を指定したい場合は、form要素の先祖要素にjs-yprox-searchForm-parentクラスを付与してください）

・その他の変更につきまして

yprox_searchForm.jsをカスタムいただくことで一部変更可能です。

以下の数値を変更可能です。 それ以外の変更は、対応外となりますのでご了承下さい。


  /**
  * DOMContentLoaded
  */
document.addEventListener('DOMContentLoaded', function () {
  const nInitDay = 1;		        // 日付(○日後) ※本日の場合は 0
  const nInitPer = 2;		        // 人数
  const nInitStay = 1;		        // 泊数
  const nInitRoom = 1;		        // 部屋数

  const nOpMaxYear = 2;			// 日付(今年も含めて何年分表示するか)
  const nOpMaxPer = 10;		        // 人数(最大選択値)
  const nOpMaxNights = 10;		// 泊数(最大選択値)
  const nOpMaxRoom = 20;		// 部屋数(最大選択値)

  let flagNoDate = false;		// 初期表示日付(日付なし)の場合は true 、formタグへ data-no-date を付与で日付なし

  let flagCalendar = false;             // カレンダーを表示する場合は true 、formタグへ data-calendar を付与でカレンダー表示

  const windowMobileWidth = 767; //モバイルの画面幅

  const nInitCalendar = 2; //カレンダーの月の表示数
  const nInitCalendarMobile = 1; //windowMobileWidth以下の画面幅でのカレンダーの月の表示数

  const calendarSpanStr = ' - '; //カレンダーの日付の間に入れる文字 初期表示にしたい場合は null

  const wr_wait = 600; // リサイズイベント発生時の待ち時間

- スタイルの変更について

formに対して、「yprox_theme--default」クラスを付与しており、そちらでデフォルトのスタイル設定を行っております。
不要であれば「「yprox_theme--default」」は削除ください。※該当ファイル：yprox_searchForm_theme.css

スタイルのカスタマイズなどはWEBサイト制作者様側で設定をお願いします。その際、「yprox_theme--default」以外の既に指定している各種class名や属性など変更しないようにご注意下さい。
